## 一、GPU 硬件执行层

### 1. SM（Streaming Multiprocessor）

GPU 的基本计算单元。  
一个 GPU 由多个 SM 组成，每个 SM 内包含：

- CUDA Cores（普通计算单元）
    
- Tensor Cores（矩阵计算单元）
    
- Warp Scheduler
    
- Register File
    
- Shared Memory
    

可以理解为：  
一个 SM 是一个能够并行执行很多线程的小型计算核心。

---

### 2. Warp

GPU 的最小调度单位。

关键特性：

- 一个 warp = **32 个线程**
    
- 32 个线程同时执行**同一条指令**
    
- 采用 **SIMT（Single Instruction Multiple Threads）** 模型
    

重要结论：  
GPU 调度的是 **warp**，不是 thread。

---

## 二、CUDA 编程模型

这些是程序员写 kernel 时直接控制的。

### 3. Thread

最小的编程单位。

每个 thread 有：

- threadIdx.x
    
- threadIdx.y
    
- threadIdx.z
    

在矩阵乘法中通常负责：

- 计算一个或多个输出元素
    

例如：  `C[row][col]`

---

### 4. Block

线程的一个集合。

特点：

- 同一个 block 内的线程运行在 **同一个 SM**
    
- 可以共享 **shared memory**
    
- 可以使用 **__syncthreads() 同步**
    

例如：

blockDim = (32,8)  
表示一个 block 有 **256 个线程**

---

### 5. Grid

所有 block 的集合。

Kernel 启动形式：

<<< gridDim , blockDim >>>

执行结构为：

Grid  
→ Block  
→ Thread

---

## 三、矩阵计算（GEMM）优化概念

这些概念不是 CUDA 固定结构，而是 **算法优化策略**。

### 6. Tile（分块）

Tile 的含义是：**把大矩阵拆成小块计算**。

原因：

- 矩阵很大，无法一次加载
    
- 分块可以利用 shared memory 做数据复用
    

例如：

大矩阵  
8192 × 8192

拆成：

32 × 32 的小块（tile）

---

### 7. Block Tile

一个 block 负责计算的矩阵块。

例如：

blockDim = (32,8)

一个 block 负责计算：

32 × 32 的 C 矩阵子块

---

### 8. Thread Tile

一个 thread 负责计算的输出块。

例如：

TY = 4

表示一个 thread 计算：

`C[row + 0][col]`
`C[row + 1][col]` 
`C[row + 2][col]`  
`C[row + 3][col]`

这样可以提高计算密度。

---

### 9. Warp Tile

一个 warp 负责计算的矩阵块。

在 Tensor Core 计算中常见，例如：

warp → 16 × 16 tile

---

## 四、GPU Memory 相关概念

### 10. Global Memory

GPU 的主显存（DRAM）。

特点：

- 容量大
    
- 访问延迟高
    
- 带宽受限
    

优化目标：  
尽量减少访问次数。

---

### 11. Shared Memory

位于 SM 内的高速缓存。

特点：

- 延迟低
    
- 带宽高
    
- 同一 block 内共享
    

典型用途：

存储 tile 数据，提高数据复用。

---

### 12. Bank

Shared memory 被分成 **32 个 bank**。

每个 bank 可以同时服务 **一个线程访问**。

如果多个线程访问：

- 同一个 bank
    
- 不同地址
    

就会产生 **bank conflict**。

---

### 13. Bank Conflict

当多个线程访问同一个 bank 时：

访问会被 **串行化**，性能下降。

解决方法：

使用 **padding** 改变内存布局。

例如：

shared memory  
32 × 32

改为：

32 × 33

这样可以改变地址映射，减少冲突。

---

## 五、Memory Access 优化

### 14. Coalesced Memory Access

Warp 的 32 个线程访问 **连续地址**。

例如：

A[i]  
A[i+1]  
A[i+2]

GPU 可以把这些访问合并为 **一个 memory transaction**。

效果：  
提高 DRAM 带宽利用率。

---

### 15. Vectorized Load

一次读取多个数据。

例如：

float4  
表示一次读取 **4 个 float（16 字节）**

优点：

- 减少 load 指令
    
- 提高带宽利用率
    

---

## 六、Tensor Core 相关概念

### 16. Fragment

Tensor Core 使用的矩阵片段。

每个 warp 持有：

- A fragment
    
- B fragment
    
- C fragment
    

fragment 实际存储在 **寄存器中**。

---

### 17. MMA（Matrix Multiply Accumulate）

Tensor Core 的核心指令：

D = A × B + C

一次执行的是 **矩阵乘法累加**。

---

## 七、整体层级结构总结

### GPU 硬件层

GPU  
→ SM  
→ Warp（32 threads）

---

### CUDA 编程层

Grid  
→ Block  
→ Thread

---

### GEMM 算法层

Matrix  
→ Block Tile  
→ Warp Tile  
→ Thread Tile
